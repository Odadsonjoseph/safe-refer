# Safe Refer — Design System

## Brand
- **Primary**: Sky Blue `#38BDF8` (light) / `#0EA5E9` (medium) / `#0284C7` (dark)
- **Background**: `#FFFFFF` (white), `#F0F9FF` (blue-tint surface)
- **Text**: `#0F172A` (heading), `#475569` (body), `#94A3B8` (muted)
- **Success**: `#22C55E`, **Warning**: `#F59E0B`, **Danger**: `#EF4444`
- **Border**: `#E2E8F0`

## Typography
- **Font**: Plus Jakarta Sans (Google Fonts)
- **Heading**: 700 weight, tight tracking
- **Body**: 400/500 weight, 1.6 line-height
- **Labels/Caps**: 600 weight, uppercase tracking-wide

## Spacing & Radius
- Base unit: 4px
- Cards: `rounded-xl` (12px), Buttons: `rounded-lg` (8px)
- Generous padding, clean whitespace

## Mobile
- White backgrounds, sky-blue accents, bottom tab bar
- Cards with soft shadow `shadow-sm`
- Status badges: colored pill chips

## Web Dashboard
- Sidebar navigation (left), clean top bar
- Table-first layout for admin data
- Sky blue buttons, white cards, light gray sidebar

## Vibe
Clean, trustworthy, professional. No gradients. No clutter. Like a bank app meets a marketplace.
